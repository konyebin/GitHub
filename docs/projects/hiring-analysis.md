# Hiring analysis (demo)

Rank-based, threshold-free analysis of resume screening, assessment center scores and notes, and interviewer trends.

**Everything on this page uses fully synthetic data.** No real candidate data is published here.

- [Open the dashboard](/demos/hiring-analysis/index.html): aggregates only, small groups hidden. This is the only build that is ever published; the local build (with candidate IDs) stays on your machine.

Never publish real candidate data to this site. For real data, run the pipeline locally; see `hiring-analysis/README.md`.
