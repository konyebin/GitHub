# Competency Board

A customizable kanban-style board for deciding which skills are **core** and which are **nice to have** for a Cisco Systems Engineer. Folder: `competency-board/`.

## Use it

Open `competency-board/index.html` in a browser. No install, no server.

- Add columns dynamically, add items to each column, and drag everything (items and columns) into place.
- Start from the Cisco SE template (Core Competencies, Nice to Have, To Sort) or a blank board.
- Notes and tags per item, filter, undo/redo, light/dark theme.
- Autosaves in the browser; export JSON (backup/share) or Markdown (paste into a doc).
