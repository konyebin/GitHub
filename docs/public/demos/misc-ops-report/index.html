How the data works

  1. Generate CSVs — Synthetic exports matching real Webex report column headers (CDR, Call Queue, AA Summary, Media Quality, Connectivity).
  2. Compute scorecard — Same formulas as production wxops generate_misc_report.py (sum/aggregate/count on CSV columns).
  3. Render dashboard — Interactive HTML with §0 Data Provenance linking each metric to its source file and formula.
  4. Reproducible — Each scenario uses a fixed random seed; re-run generate_demo_reports.py to regenerate.
