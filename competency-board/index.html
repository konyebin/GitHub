How it works

  • Add columns with the tile at the far right. Rename by clicking a column title; use the … menu for color, description, duplicate, move and delete.
  • Add items at the bottom of any column. Enter adds, Shift+Enter starts a new line. Pasting a multi-line list (bullets and numbers are stripped) adds one item per line.
  • Drag cards between columns or to reorder; drag a column by its header to reorder columns. On touch screens, use the grip handle.
  • Edit an item by double-clicking it or pressing Enter / F2 when focused. Add notes, a tag, or move it to another column.
  • Keyboard: Alt+Arrows move the focused card; Delete removes it; / filters; Ctrl/Cmd+Z undoes.
  • Saved automatically in this browser. Use Export for JSON backups or Markdown to paste into a doc, and Import to restore.
